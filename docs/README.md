# Project Overview

## Project Title

Passive Cooling Design for a House

## Introduction

This project focuses on designing a residential building using passive cooling principles to improve indoor thermal comfort and reduce dependence on mechanical cooling systems.

The design uses architectural and engineering techniques such as building orientation, natural ventilation, shading, roof insulation, and appropriate material selection.

## Project Aim

To develop an energy-efficient house design that uses natural methods to reduce indoor heat gain and improve thermal comfort.

## Engineering Focus

- Heat transfer
- Thermal insulation
- Solar heat gain
- Natural ventilation
- Building orientation
- CAD modelling
- Thermal comfort

## 🖥️ CAD Design

The house was developed using Computer-Aided Design (CAD) to create and visualize the proposed passive cooling building layout.

### CAD Model Includes

- Complete house floor layout
- Room arrangement
- Doors and windows
- Ventilation openings
- Roof design
- Shading elements
- Wall and building dimensions
- Passive cooling features
- Overall building arrangement

### CAD Design Objectives

- Develop an accurate house layout
- Optimize window and ventilation locations
- Incorporate natural ventilation paths
- Provide suitable shading for openings
- Visualize the proposed passive cooling concept
- Prepare the model for further engineering analysis

# Passive Cooling House

A passive cooling house prototype designed to reduce indoor temperature using natural ventilation and climate-responsive design without electricity.

## Project Objective

The main objective is to develop a low-cost house design that can reduce indoor heat using passive cooling methods.

## Key Features

- Passive cooling design
- Natural ventilation
- Reduced heat gain
- Climate-responsive house design
- Low-cost construction approach
- No external cooling equipment

## Project Structure

- `images/` – Project photographs and prototype images
- `CAD/` – CAD drawings and 3D models
- `hardware/` – Materials and hardware details
- `software/` – Calculations and technical files
- `docs/` – Project documentation and methodology
- `results/` – Testing and performance results

## Technologies

- CAD Modelling
- Mechanical Design
- Passive Cooling
- Thermal Design
- Prototype Development

## Future Scope

The design can be further improved through material optimization, better ventilation paths, and additional thermal testing.
